🎫 AI-Powered Ticketing System

A web-based ticketing system that allows users to log in, view AI-generated support tickets, chat within those tickets, and organize them by groups and priority—all through a sleek, Zendesk-inspired interface.

    💡 This project uses OpenAI to generate demo ticket content and simulate realistic support interactions for showcasing ticket system functionality.

🚀 Project Overview

This project leverages OpenAI’s API to generate realistic support tickets and chat responses. Users can:

    Sign in securely

    View and interact with tickets

    Create groups for better organization

    Assign priorities to tickets and groups

    View full chat histories inside each ticket

    Monitor progress through visual dashboards

🧠 Core Features
✅ Authentication & Ticketing

    Simple user login interface

    AI-generated tickets with:

        Random usernames

        Random issue summaries

        Conversational chat responses between AI and user

    Chat history saved and retrieved per ticket

📊 Ticket Organization

    Group tickets by category or department

    Assign ticket priority (Low, Medium, High, Critical)

    Create and use macro responses saved per user

    Add graphs to visualize ticket resolution progress

🧰 Tech Stack

    Frontend: HTML, CSS (Zendesk-like styling)

    Backend: Node.js

    Database: SQLite

    AI Integration: OpenAI API (GPT)

🧩 Main Development Hurdles
🔧 OpenAI Integration

    Setting up and authenticating OpenAI API in VS Code

    Generating dynamic ticket content (usernames, messages)

    Maintaining chat interaction between user and AI

🗃️ SQLite + Node.js Backend

    Creating and connecting to a local SQLite database

    Storing user credentials securely

    Storing and retrieving ticket chat history

    Structuring queries for efficient ticket/group loading

📈 Planned Enhancements

    User-defined macros for quick replies

    Group-based priority metrics

    Interactive graphs and ticket analytics

    Further GUI polishing to match professional ticketing systems like Zendesk

📸 UI Inspiration

The goal is to emulate the clean, intuitive interface of tools like Zendesk, focusing on usability and clarity while incorporating the power of AI and automation.
